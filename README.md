Task 4: Website Productivity Tracker Extension  <br> <br> 
This Chrome extension tracks the time spent on various websites and provides productivity analytics. It classifies websites as productive or unproductive, generates weekly productivity reports, and stores the data in a MySQL database via a Node.js backend. The extension offers an intuitive user interface that allows users to view their activity and monitor their productivity.
<br> <br> 

Features:      <br> 
Tracks time spent on websites in real-time.      <br> 
Classifies websites as productive or unproductive.      <br>
Provides weekly productivity reports in the popup interface.      <br>
Data is stored in a MySQL database with backend support from Node.js and Express.      <br>      <br>

Technologies:      <br>
Frontend: Chrome Extension (HTML, JavaScript, CSS)      <br>
Backend: Node.js, Express.js      <br>     
Database: MySQL      <br>      <br>

Setup Instructions:      <br>
Clone the repository.      <br>
Set up the MySQL database and configure the backend.      <br>
Load the extension in Chrome via the "Load Unpacked" option.      <br>
Track website activity and view productivity reports in the extension popup.      <br>
